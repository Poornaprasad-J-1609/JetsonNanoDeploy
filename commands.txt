GRALLATOR MEVIUS-STYLE SLCAN TEST COMMANDS
==========================================

This folder keeps the Grallator policy/observation contract and hardware
safety boundary while using the simpler MEVIUS-style actor-to-MIT target path.

The robot must be supported for initial tests. Keep physical emergency power
removal accessible. Never run two motor controllers at the same time.


0. ENTER THE FOLDER AND SET THE ENVIRONMENT
-------------------------------------------

cd ~/GRALLATOR_MEVIUS_STYLE
export PYTHONPATH="$PWD/src"
export CAN_FRONT=slcan0
export CAN_BACK=slcan1
export IMU_PORT=/dev/ttyUSB0


1. START AND VERIFY BOTH SLCAN INTERFACES
-----------------------------------------

sudo systemctl restart slcan0.service slcan1.service
sudo ip link set "$CAN_FRONT" up
sudo ip link set "$CAN_BACK" up
sudo ip link set "$CAN_FRONT" txqueuelen 32
sudo ip link set "$CAN_BACK" txqueuelen 32

ip -br link show "$CAN_FRONT"
ip -br link show "$CAN_BACK"
ip -details -statistics link show "$CAN_FRONT"
ip -details -statistics link show "$CAN_BACK"

Both interfaces must report UP before continuing.


2. PASSIVE MOTOR CONNECTION AND ENCODER CHECK
---------------------------------------------

This sends stop/poll frames only. It does not enable MIT torque.

python3 src/check_motor_connections.py \
  --can-count 2 \
  --can-ports "$CAN_FRONT" "$CAN_BACK" \
  --can-backend socketcan \
  --can-bitrate 1000000 \
  --all \
  --rate 20 \
  --print-every 0.5 \
  --disable-set-zero-key \
  --disable-crouch-key \
  --disable-four-bar-transmission

Expected: 12/12 CONNECTED, fresh feedback, fault 0x00. Press q to quit.


3. PASSIVE FRONT-LEG CONNECTION CHECK
-------------------------------------

python3 src/check_motor_connections.py \
  --can-count 2 \
  --can-ports "$CAN_FRONT" "$CAN_BACK" \
  --can-backend socketcan \
  --can-bitrate 1000000 \
  --active-joints \
    FR_hip_joint FR_thigh_joint FR_calf_joint \
    FL_hip_joint FL_thigh_joint FL_calf_joint \
  --rate 20 \
  --print-every 0.5 \
  --disable-set-zero-key \
  --disable-crouch-key \
  --disable-four-bar-transmission


4. PASSIVE 200 HZ TWO-ADAPTER TRANSPORT BENCHMARK
-------------------------------------------------

python3 scripts/benchmark_can_control_cycle.py \
  --can-count 2 \
  --can-interfaces "$CAN_FRONT" "$CAN_BACK" \
  --motors 12 \
  --rate 200 \
  --duration 20 \
  --bitrate 1000000 \
  --feedback-freshness-window 0.040 \
  --details

Do not continue if transport qualification fails or feedback becomes stale.


5. REAL XSENS IMU CHECK WITHOUT MOTOR CONTROL
---------------------------------------------

python3 src/imu_interface.py \
  --source xsens \
  --port "$IMU_PORT" \
  --seconds 20 \
  --hz 100


6. SIT/STAND-ONLY TEST: POLICY CANNOT START
-------------------------------------------

bash scripts/run_sit_stand_gain_test.sh

Keys:
  c       crouch
  Space   stand
  h       hold current pose
  x       emergency stop

Confirm crouch and stand are smooth, complete, and free of faults before any
walking test. This runner uses --pose-test-only and disables policy takeover.


7. PRINT THE COMPLETE MEVIUS-STYLE WALK COMMAND WITHOUT HARDWARE
---------------------------------------------------------------

DRY_RUN=1 bash scripts/run_mevius_style_walk.sh \
  --speed-scale-initial 0.03 \
  --speed-scale-min 0.03 \
  --speed-scale-max 0.05 \
  --policy-command-vx-max 0.08 \
  --policy-command-vy-max 0.06 \
  --policy-command-yaw-max 0

Verify the printed command contains:
  --policy-path <this folder>/policy/policy.pt
  --exact-policy-after-entry
  --policy-action-smoothing 0
  --policy-action-delta-limit 0
  --auto-policy-after-stand


8. LOW-SPEED SUPPORTED MEVIUS-STYLE WALK TEST
---------------------------------------------

bash scripts/run_mevius_style_walk.sh \
  --speed-scale-initial 0.03 \
  --speed-scale-min 0.03 \
  --speed-scale-max 0.05 \
  --speed-scale-step 0.01 \
  --policy-command-vx-max 0.08 \
  --policy-command-vy-max 0.06 \
  --policy-command-yaw-max 0 \
  --log-every 1 \
  --no-auto-push-log

Sequence:
  1. Press c and wait for crouch to complete.
  2. Press Space and wait for stand to settle.
  3. Confirm the controller reports automatic policy entry at zero command.
  4. Wait for the 3-second entry blend to reach 100 percent.
  5. Press w once to request low-speed forward movement.
  6. Press h to stop walking and hold, c to crouch, or x for emergency stop.

Movement keys:
  w/s     forward/backward
  a/d     left/right
  q/e     yaw left/right
  arrows  adjust speed scale


9. FIND THE LATEST LOG
----------------------

find logs -type f -name 'grallator_run_*.csv' -size +0c \
  -printf '%T@ %p\n' | sort -nr | head -n 5


10. STOP THE SLCAN SERVICES AFTER TESTING
-----------------------------------------

sudo systemctl stop slcan0.service slcan1.service
ip -br link | grep -E 'can|slcan'
