GRALLATOR_DEPLOY command guide
==============================

Run all commands from this folder:

cd /path/to/GRALLATOR_DEPLOY

For a migrated system, change only these three device variables after checking
which /dev/ttyUSB* belongs to each device:

export FRONT_CAN=/dev/ttyUSB0
export BACK_CAN=/dev/ttyUSB1
export IMU_PORT=/dev/ttyUSB2
export PYTHONPATH="$PWD/src"

If the GUI does not open from a desktop terminal, check:

echo $DISPLAY
export DISPLAY=:0

Install Python requirements:

/usr/bin/python3 -m pip install -r requirements.txt

Ubuntu/Debian GUI dependency if tkinter is missing:

sudo apt-get update
sudo apt-get install -y python3-tk


1. Port check
-------------

ls -l /dev/ttyUSB* /dev/input/js* /dev/input/event* 2>/dev/null

/usr/bin/python3 src/check_can_routing.py


2. Joystick connection test
---------------------------

/usr/bin/python3 src/joystick_interface.py \
  --source joystick \
  --list-joysticks \
  --joystick-wait-seconds 10

To see raw axes/buttons:

/usr/bin/python3 src/joystick_interface.py \
  --source joystick \
  --joystick-wait-seconds 10 \
  --seconds 30 \
  --hz 20 \
  --show-raw

Main controller joystick workflow:

1. Start with the robot manually in crouch/default pose.
2. The controller automatically software-zeros the current crouch/default pose
   from live encoder feedback at startup. D-pad down is optional and can still
   be used to recalibrate manually before standing.
3. Press button 5 to stand. When stand settles, the controller auto-applies
   software zero again, so stand becomes q=0 for the RL policy.
4. Button 4 returns to sit/crouch. Button 3 emergency-stops. From crouch-zero
   hold, button 1 runs namaste, button 2 runs hi, and button 0 runs the user
   gesture slot.

6. Motor set zero
-----------------

Put the robot manually in its stand/default pose, then run:

/usr/bin/python3 src/check_motor_connections.py \
  --port-front "$FRONT_CAN" \
  --port-back "$BACK_CAN" \
  --all \
  --rate 20 \
  --print-every 1.0 \
  --gui-only
  

Keyboard while this command is running:

s = send RobStride set-zero to all active motors and save default_pose/stand_pose as zero
q = quit


7. Motor set zero plus set crouch pose
--------------------------------------

Step 1: manually put the robot in stand/default pose and press s.
Step 2: manually put the robot in crouch/sit pose and press c.
Step 3: press q to quit.

/usr/bin/python3 src/check_motor_connections.py \
  --port-front "$FRONT_CAN" \
  --port-back "$BACK_CAN" \
  --all \
  --rate 20 \
  --print-every 1.0 \
  --gui-only

Keyboard while this command is running:

s = set current motor positions as zero/default/stand
c = save current feedback angles as crouch_pose in config/default_pose.yaml
q = quit

9. Sit/stand and crouch-zero gimmick test, no walking
-----------------------------------------------------

This sends real MIT commands. Keep the robot suspended/secured.
Joystick walking is disabled by the huge walk threshold and zero velocity limits.
After launch:
1. Put robot in manual crouch/default pose.
2. Press f to software-zero crouch/default and hold. Startup auto-zero also
   tries this once at launch.
3. From crouch-zero hold, press b for gesture_0, n for namaste, and h for hi.
4. Press w to stand. When stand settles, the controller auto-zeros stand.
5. Press s to sit/crouch. When sit settles, the controller auto-zeros crouch
   again so b/n/h gimmicks are enabled. Press x for emergency stop.

/usr/bin/python3 src/main_controller.py \
  --mode mit-signal \
  --port-front "$FRONT_CAN" \
  --port-back "$BACK_CAN" \
  --feedback-source mit \
  --command-source keyboard \
  --imu-source xsens \
  --imu-port "$IMU_PORT" \
  --imu-stabilization \
  --no-gait-assist \
  --base-lin-vel-source zero \
  --start-control-mode hold \
  --startup-action hold \
  --initial-zero-frame crouch \
  --auto-zero-on-startup \
  --auto-stand-zero \
  --auto-sit-zero \
  --zero-calibration-hat-index 0 \
  --zero-calibration-hat-direction 0 -1 \
  --no-zero-calibration-hat-any \
  --zero-calibration-axis -1 \
  --button-speed-down -1 \
  --button-speed-up -1 \
  --button-emergency-stop 3 \
  --gestures \
  --keyboard-gestures \
  --gesture-config config/gestures.yaml \
  --policy-steps 0 \
  --walk-command-threshold 999 \
  --max-vx 0.0 \
  --max-vy 0.0 \
  --max-yaw 0.0 \
  --speed-scale-initial 0.05 \
  --speed-scale-min 0.05 \
  --speed-scale-max 0.05 \
  --feedback-timeout 0.03 \
  --pose-sync-error-rad 0.12 \
  --log-every 5 \
  --joint-debug \
  --gui


10. Walk control with policy, real IMU, joystick
------------------------------------------------

This sends real MIT commands. First full robot tests should be suspended/secured.
Runtime speed buttons are disabled while testing gimmicks. Emergency stop is
joystick button 3. Ctrl+C also stops.
After launch: press button 5 to stand, wait for "zero_frame -> stand", then
move the joystick sticks. D-pad zero is optional.
